# Wijhan Corporate Website

## Build
- Create a shared, responsive site shell with navigation, footer, mobile menu, and consistent calls to action.
- Build Home, About, Services, Work, Process, and Contact pages with the supplied English content and brand positioning.
- Use the specified navy, bone, teal, amber, Inter, Fraunces, and IBM Plex Sans Arabic design system.
- Add restrained editorial motion, geometric direction motifs, accessible controls, and mobile-specific layouts.
- Keep case studies and contact details explicitly marked as awaiting official information; do not fabricate claims.
- Add unique search and social metadata for every page.

## Brand Asset Note
- No uploaded logo file is currently available in the project. Use a respectful text lockup for “Wijhan | وِجهان” as a temporary placeholder without recreating the symbol, and make it easy to replace when the official asset is supplied.

## Validation
- Verify every page, navigation path, contact form behavior, responsive layout, accessibility basics, and metadata in the running preview.

## Technical Details
- Implement with the existing TanStack Start and Tailwind v4 setup.
- Keep reusable content and layout elements in focused shared components.
- Use semantic design tokens and avoid adding persistent data or backend services; the contact form will validate locally and clearly indicate that submission is not yet connected.
